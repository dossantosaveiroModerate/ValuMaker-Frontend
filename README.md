## 2. サービス概要 (Level 0: 要件定義)
- **サービス名**: Valu-Maker (バリューメーカー)
- **コンセプト**: 「個人の挑戦を価値に変える」。日々の学びや実践を投稿し、その活動量を「株価」のようなチャートで可視化して、相互に応援・投資し合えるプラットフォームです。
- **開発背景**: 実家の米農家での経験や、アントレプレナーシップ学部での学びを通じ、目に見えにくい「努力」や「プロセス」を価値として可視化したいと考え開発しました。

## 3. 主要機能
- **投稿・タイムライン機能**: 自分のアクションを即座に共有できます。
- **投稿削除機能**: サーバーサイド（Actions）を通じた投稿の管理が可能です。
- **チャート可視化機能**: ユーザーの時価総額推移をグラフで表示します。
- **多言語対応(日本語化)**: Clerk 認証や UI を日本語に最適化済み。
